# Test Textures

Sample textures for manually verifying **TextureChannelPacker**. Import them into any UE project that has the plugin enabled, then follow the checks below.

They are generated by [`generate_test_textures.py`](generate_test_textures.py) (pure standard library — no Pillow/numpy needed):

```
python3 generate_test_textures.py
```

## Import settings

The tool reads a texture's **Source** data (the raw imported pixels), so the `sRGB` import flag does **not** change the values it extracts — it only changes how the texture looks in the Content Browser. For the packed samples, setting **Compression = Masks** and **sRGB = off** after import still makes the previews match what the tool reports.

The 16-bit sample must keep its precision: leave **Compression = Grayscale** on it, and do not let the importer downconvert it to 8-bit.

## Files

| File | Size | Format | Purpose |
| :--- | :--- | :--- | :--- |
| `T_UnpackTest_ORM.png` | 512×512 | RGBA8 | Main unpack test. Four unmistakable patterns, one per channel. |
| `T_UnpackTest_Uniform_ORM.png` | 256×256 | RGBA8 | Unused-channel detection. B is uniformly 0, A uniformly 255. |
| `T_UnpackTest_NonSquare_ORM.png` | 512×128 | RGBA8 | Non-square aspect handling in the preview grid and outputs. |
| `T_TestMaterial_AO.png` | 512×512 | Gray8 | Pack input (Red / Ambient Occlusion). Centre-bright vignette. |
| `T_TestMaterial_Roughness.png` | 256×256 | Gray8 | Pack input (Green / Roughness). **Half resolution on purpose** — exercises auto-resize. |
| `T_TestMaterial_Metallic.png` | 512×512 | Gray8 | Pack input (Blue / Metallic). Hard-edged circle mask. |
| `T_TestMaterial_Height16.png` | 512×512 | Gray16 | 16-bit source path (`TSF_G16`). Smooth sine/cosine field. |

## Check 1 — Unpack

1. Open **Tools > Texture Channel Packer**, switch to the **Unpack** tab, preset **ORM**.
2. Assign `T_UnpackTest_ORM`.

Expected, immediately on selection (no button press):

| Cell | Pattern | Output name |
| :--- | :--- | :--- |
| **R → AO** | Smooth left-to-right gradient | `T_UnpackTest_AO` |
| **G → Roughness** | Hard-edged checkerboard | `T_UnpackTest_Roughness` |
| **B → Metallic** | Smooth concentric rings | `T_UnpackTest_Metallic` |
| **A** | Hard-edged diagonal stripes | `T_UnpackTest_A` |

This confirms three things at once: the channels are not swapped, smart naming stripped the `_ORM` suffix (`T_UnpackTest_ORM` → `T_UnpackTest`), and the preset supplied the per-channel suffixes.

Click **Unpack Textures** — four G8 assets appear with `Grayscale` compression and `sRGB` off, each 512×512.

Switching the preset to **MRA** should relabel the cells (`R → Metallic`, `B → AO`) and rename the outputs accordingly, without touching the images.

## Check 2 — Unused-channel detection

Assign `T_UnpackTest_Uniform_ORM`. Expected:

- **R** and **G** show content (vignette / vertical gradient) and stay checked.
- **B** shows solid black, is badged **Uniform (0)**, and is unchecked automatically.
- **A** shows solid white, is badged **Uniform (255)**, and is unchecked automatically.

Clicking **Unpack Textures** now produces only two assets. Re-checking B exports it anyway — the badge is advisory, not a lock.

## Check 3 — Non-square

Assign `T_UnpackTest_NonSquare_ORM` (4:1). The four preview cells must stay 4:1 rather than stretching to square, and the extracted assets must be 512×128.

## Check 4 — Pack

On the **Pack** tab with preset **ORM**, assign:

- Red ← `T_TestMaterial_AO`
- Green ← `T_TestMaterial_Roughness` (256×256)
- Blue ← `T_TestMaterial_Metallic`
- Alpha ← leave empty

The file name should auto-fill as `T_TestMaterial_ORM`. Set the resolution to 512×512 and press **Update Preview**: the **View** dropdown should show the vignette on R, the blobs on G (upscaled from 256), the circle on B, and solid white on A.

Generate, and the result is your round-trip input for the next check.

## Check 5 — Round trip

Unpack the `T_TestMaterial_ORM` you just generated.

- **R (AO)** and **B (Metallic)** should come back **pixel-identical** to the originals — both were packed at their native 512×512, and every step is 8-bit with no resampling.
- **G (Roughness)** will *not* be identical: it was upscaled 256→512 with bilinear filtering during packing, and that is not reversible.
- **A** should be badged **Uniform (255)**, since the empty alpha slot was filled with white during packing.

## Check 6 — 16-bit source

Assign `T_TestMaterial_Height16` to any Pack slot. It should read as a smooth field rather than black or banded noise, confirming the `TSF_G16` path converts 16-bit to 8-bit correctly.

It is also worth dropping it into the Unpack tab: as a single-channel source, R/G/B all show the same field and **A is reported as Uniform (255)**.
